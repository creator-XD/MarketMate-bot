# Руководство по админ-панели

Документ описывает настройку, права и основные сценарии администрирования Telegram Marketplace Bot.

## Назначение

Админ-панель нужна для контроля пользователей, объявлений, жалоб, отзывов и журнала действий. Доступ защищён несколькими уровнями: Telegram ID в `.env`, активная роль администратора в базе и проверка конкретного права.

## Роли

| Роль | Назначение |
| --- | --- |
| `super_admin` | Полный доступ, включая управление администраторами. |
| `admin` | Управление пользователями, объявлениями, отзывами, жалобами и аудитом. |
| `moderator` | Модерация объявлений, предупреждения и просмотр аналитики. |

Технические имена ролей не переводятся, потому что используются в коде и базе данных.

## Настройка доступа

1. Добавьте Telegram ID администратора в `.env`:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
SUPER_ADMIN_ID=123456789
```

2. Запустите бота и отправьте `/start` от имени будущего администратора.
3. Создайте запись администратора:

```bash
python scripts/create_admin.py
```

4. Проверьте настройку:

```bash
python scripts/check_admin_setup.py
```

## Вход в панель

В Telegram отправьте команду:

```text
/admin
```

Если доступ настроен правильно, бот покажет главное меню админ-панели.

## Основные разделы

### Пользователи

Просмотр пользователей, фильтрация списков, карточка пользователя, блокировка и разблокировка, предупреждения и история предупреждений.

### Объявления

Просмотр объявлений, подробная карточка, отметка подозрительных объявлений, снятие отметок и удаление при наличии права `delete_any_listing`.

### Отзывы

Просмотр отзывов и удаление нарушающих правила записей через подтверждение.

### Транзакции

Раздел подготовлен для будущей платёжной логики. Сейчас он показывает сохранённые записи транзакций и фильтры по статусам.

### Аналитика

Показывает агрегированную статистику по пользователям, объявлениям и транзакциям.

### Журнал аудита

Хранит действия администраторов: блокировки, предупреждения, удаление объявлений, модерацию и другие операции.

## Безопасность

- Не храните реальный `BOT_TOKEN` в коде.
- Не добавляйте `.env` в систему контроля версий.
- Выдавайте минимально необходимые права.
- Для опасных действий используйте подтверждение через inline-кнопки.
- Проверяйте `admin_audit_log` при разборе спорных ситуаций.

## Диагностика

Если `/admin` не открывается:

1. Проверьте, что Telegram ID есть в `ADMIN_TELEGRAM_IDS`.
2. Убедитесь, что пользователь уже отправил `/start`.
3. Запустите `python scripts/create_admin.py`.
4. Запустите `python scripts/check_admin_setup.py`.
5. Проверьте, что запись администратора активна в таблице `admin_users`.

## Связанные файлы

- `handlers/admin/admin_router.py` — вход и главное меню.
- `handlers/admin/user_management.py` — управление пользователями.
- `handlers/admin/listing_management.py` — модерация объявлений.
- `handlers/admin/review_management.py` — управление отзывами.
- `handlers/admin/audit.py` — журнал действий.
- `keyboards/admin_keyboards.py` — клавиатуры админ-панели.
- `database/admin_models.py` — модели админов, аудита и предупреждений.

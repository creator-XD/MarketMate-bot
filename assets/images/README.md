# Изображения проекта

В этой папке хранятся статические изображения, которые бот отправляет пользователям.

## Файлы

- `menu.jpg` — изображение приветственного меню, используется при `/start` и возврате в главное меню.

## Требования

- Формат: JPG или PNG.
- Рекомендуемый размер: до 5 МБ.
- Изображение должно хорошо читаться в мобильном интерфейсе Telegram.

Если файл приветственного меню меняется, проверьте путь `WELCOME_IMAGE_PATH` в `config.py`.

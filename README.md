# Telegram Marketplace Bot

Telegram-бот для покупки и продажи товаров и услуг, построенный на Python и aiogram 3.x. Включает полноценную админ-панель с управлением пользователями/объявлениями, журналом действий и ролевой системой доступа. Оформлен как русскоязычный учебный проект на Python и aiogram 3.x.


## Возможности

### Пользовательские функции
- **Управление профилем** — Автоматическая регистрация по `/start`, редактирование профиля (телефон, местоположение, описание)
- **Управление объявлениями** — Создание, редактирование, удаление и пометка как проданных; до 5 фото на объявление
- **Состояние товара** — Каждое объявление содержит поле состояния: Новый, Б/у или Хорошее состояние; отображается в карточке товара и доступно для редактирования после создания
- **Поиск и фильтрация** — Поиск по ключевым словам, просмотр по категориям, фильтр по цене, поиск по продавцу (username или имя), поиск по городу/местоположению, пагинация
- **Категории** — 10 категорий товаров с эмодзи (электроника, одежда, дом и сад, транспорт, услуги, работа, животные, спорт, книги, другое)
- **Сообщения покупатель-продавец** — Прямое общение через бота; продавец получает уведомление с кнопкой **Ответить**; покупатель получает ответ продавца с кнопкой **Написать снова**; уведомления отправляются на языке каждого пользователя
- **Избранное** — Сохранение и управление интересными объявлениями
- **Рейтинги и отзывы продавцов** — Оценка продавцов (1–5 звёзд), комментарии, просмотр истории отзывов с агрегированными рейтингами
- **Страница объявлений продавца** — Из карточки любого объявления покупатель может посмотреть все активные объявления этого продавца
- **Жалобы** — Возможность пожаловаться на объявление или продавца прямо из карточки товара; выбор причины (спам, мошенничество, неприемлемый контент, неверная категория и др.); опциональный комментарий; повторные жалобы блокируются; при достижении 3 жалоб объявление автоматически получает отметку; все активные администраторы мгновенно получают уведомление
- **Исправление пагинации** — Кнопка «Назад» из карточки объявления всегда возвращает на ту же страницу результатов поиска с корректным индикатором страницы и кнопками навигации
- **Мультиязычность** — Полная поддержка русского и английского языков через команды `/russian` и `/english`; язык сохраняется между сессиями и переключается без потери состояния FSM
- **Приветственное изображение** — Визуальное главное меню с брендированной картинкой

### Админ-панель
- **Панель управления** — Статистика в реальном времени: пользователи (всего, активные, заблокированные, верифицированные, новые за день/неделю), объявления (всего, активные, проданные, отмеченные, новые за день/неделю), транзакции
- **Управление пользователями** — Просмотр/фильтрация (все, активные, заблокированные, верифицированные), блокировка/разблокировка с указанием причины, выдача предупреждений (низкая/средняя/высокая серьёзность), история предупреждений, просмотр объявлений пользователя
- **Управление объявлениями** — Просмотр/фильтрация (все, активные, отмеченные, удалённые), отметка/снятие отметки с указанием причины, удаление, просмотр информации о продавце
- **Уведомления о жалобах** — Администраторы мгновенно получают сообщение при каждой жалобе: имя пользователя, объект, причина, комментарий и суммарное количество жалоб; при автоматической отметке объявления добавляется соответствующее уведомление
- **Журнал действий** — Автоматическое логирование всех действий администраторов с фильтрацией (блокировки, предупреждения, удаления, редактирования) и пагинацией
- **Ролевой доступ** — Три роли (super_admin, admin, moderator) с детальными правами доступа
- **Безопасность** — Трёхуровневая авторизация: белый список в `.env` → проверка роли в БД → проверка прав доступа

## Установка

1. **Клонируйте репозиторий**

2. **Создайте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения**:
   Создайте файл `.env` в корне проекта (см. `.env.example`):
   ```env
   BOT_TOKEN=ваш_токен_от_botfather
   ADMIN_TELEGRAM_IDS=123456789,987654321
   SUPER_ADMIN_ID=123456789
   ```

5. **Запустите бота**:
   ```bash
   python bot.py
   ```

6. **Настройте первого администратора** (после того как админ отправит `/start` боту):
   ```bash
   python scripts/create_admin.py
   ```

## Конфигурация

Все настройки находятся в `config.py`, конфиденциальные значения загружаются из `.env`:

| Параметр | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота Telegram (от @BotFather) | Обязательный |
| `DATABASE_URL` | Строка подключения к БД | `marketplace.db` (SQLite) |
| `ADMIN_TELEGRAM_IDS` | ID администраторов через запятую | Пусто |
| `SUPER_ADMIN_ID` | ID суперадминистратора | Нет |
| `MAX_PHOTOS` | Макс. фото на объявление | 5 |
| `MAX_TITLE_LENGTH` | Макс. длина заголовка | 100 |
| `MAX_DESCRIPTION_LENGTH` | Макс. длина описания | 2000 |
| `MIN_PRICE` / `MAX_PRICE` | Диапазон цен | 0.01 – 1 000 000 |
| `PAGE_SIZE` | Элементов на странице (пользователь) | 5 |
| `ADMIN_PAGE_SIZE` | Элементов на странице (админ) | 10 |
| `CURRENCY` | Символ валюты | `₽` |

## База данных

### Движок
SQLite по умолчанию (`marketplace.db`, создаётся автоматически при первом запуске). Доступен путь миграции на PostgreSQL.

### Схема

| Таблица | Описание |
|---|---|
| `users` | Аккаунты, профили, язык интерфейса, статус верификации, информация о блокировке, счётчик предупреждений |
| `listings` | Объявления с полями статуса, состояния товара, просмотров и отметок |
| `listing_photos` | Фотографии объявлений (Telegram file_id, флаг основной фото) |
| `favorites` | Избранные объявления пользователей |
| `messages` | Сообщения покупатель-продавец со статусом прочтения |
| `transactions` | Платёжные транзакции (заглушка) |
| `reviews` | Отзывы о продавцах с рейтингами (1–5), комментариями и привязкой к объявлениям |
| `user_reports` | Жалобы пользователей на объявления и других пользователей (причина, комментарий, статус, уникальность по паре репортёр/цель) |
| `admin_users` | Роли и права администраторов (JSON) |
| `admin_audit_log` | Журнал всех действий администраторов |
| `user_warnings` | Предупреждения пользователям с уровнями серьёзности |

### Переход на PostgreSQL
1. Установите `asyncpg`: `pip install asyncpg`
2. Обновите `DATABASE_URL` в `.env`:
   ```
   DATABASE_URL=postgresql://user:password@localhost/marketplace
   ```
3. Обновите драйвер БД в `database/db.py`

## Использование

### Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота, отображение главного меню с приветственным изображением |
| `/search` | Поиск объявлений |
| `/mylistings` | Просмотр ваших объявлений |
| `/favorites` | Просмотр избранного |
| `/profile` | Просмотр/редактирование профиля |
| `/help` | Справочная информация |
| `/cancel` | Отмена текущей операции |
| `/russian` | Переключить язык интерфейса на русский |
| `/admin` | Открыть админ-панель (только для администраторов) |

### Для покупателей
1. `/start` для регистрации и отображения главного меню
2. Просматривайте объявления или используйте поиск с фильтрами
3. Фильтруйте по категории, ключевым словам, диапазону цен, городу или ищите по имени/username продавца
4. Смотрите состояние товара, рейтинги и отзывы продавца перед покупкой
5. Просматривайте все активные объявления продавца прямо из карточки товара
6. Свяжитесь с продавцом через бота; используйте кнопку **Ответить** в уведомлении для быстрого ответа
7. Сохраняйте интересные товары в избранное
8. Оставляйте отзывы и рейтинги после сделок
9. Жалуйтесь на подозрительные объявления или продавцов кнопкой **🚩 Пожаловаться**

### Для продавцов
1. Перейдите в «Мои объявления» → «Добавить объявление»
2. Следуйте подсказкам: название → описание → цена → категория → **состояние** → фото
3. Управляйте объявлениями (редактируйте название, описание, цену, категорию, состояние, фото)
4. Отвечайте на запросы покупателей кнопкой **Ответить покупателю** прямо в уведомлении

### Админ-панель
1. Убедитесь, что ваш Telegram ID указан в `ADMIN_TELEGRAM_IDS` в `.env`
2. Отправьте `/start` боту, затем выполните `python scripts/create_admin.py`
3. Используйте `/admin` для входа в админ-панель
4. Навигация: Панель управления, Пользователи, Объявления, Журнал действий
5. Получайте мгновенные уведомления о жалобах пользователей на объявления и продавцов

#### Роли администраторов

| Роль | Права доступа |
|---|---|
| `super_admin` | Все права, включая управление администраторами |
| `admin` | Все права, кроме управления администраторами |
| `moderator` | Управление объявлениями, предупреждения, аналитика, редактирование объявлений |

## Архитектура

### Приоритет роутеров
Роутеры регистрируются в следующем порядке (ранний = более высокий приоритет):
1. `admin_router` — Админ-панель и все подроутеры
2. `listings_router` — CRUD-операции с объявлениями
3. `search_router` — Поиск и фильтрация (ключевые слова, категория, цена, продавец, город)
4. `messages_router` — Общение покупатель-продавец
5. `reviews_router` — Рейтинги и отзывы продавцов
6. `reports_router` — Жалобы пользователей на объявления и продавцов
7. `profile_router` — Управление профилем
8. `common_router` — Общие обработчики (/start, /help, /cancel, переключение языка)

### FSM-состояния
- **ListingStates** — 8 состояний создания (включая состояние товара) + 6 состояний редактирования (включая состояние товара)
- **SearchStates** — 7 состояний поиска (ключевые слова, категория, цена, продавец, город)
- **MessageStates** — 2 состояния сообщений
- **ProfileStates** — 3 состояния редактирования профиля
- **ReviewStates** — 2 состояния отзывов (рейтинг, комментарий)
- **ReportStates** — 1 состояние (опциональный комментарий к жалобе)
- **AdminStates** — 6 состояний админ-операций (блокировка, предупреждение, отметка, редактирование, удаление, фильтрация)

### Middleware
- **LanguageMiddleware** — Читает язык пользователя из БД при каждом запросе и передаёт `lang` во все обработчики
- **AdminAuthMiddleware** — Выполняется при каждом сообщении/callback, добавляет `admin` и `is_admin` в данные обработчика
- **AuditLoggerMiddleware** — Автоматически логирует действия администраторов после выполнения обработчика

### Паттерны callback-данных
- Простые: `"action"` (например, `"help"`, `"cancel"`)
- С ID: `"action:id"` (например, `"view_listing:123"`)
- Пагинация: `"action:page"` (например, `"browse:2"`)
- С несколькими параметрами: `"action:param1:param2"` (например, `"report_reason:listing:123:spam"`)
